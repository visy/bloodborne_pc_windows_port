## Ranked changes worth porting
1. Drop (or downgrade to LOG_ERROR + skip) `ASSERT(dma_data->command.das == 0)` at liverpool.cpp:525 and :2436.
   Risk: a DAS=1 packet then executes as a normal memory DMA with wrong semantics (dst is a register/GDS-like space); safest is `if (das) { LOG_WARNING; return; }` rather than blind execution. Test: run a long session (BB_FRAME_STATS=1), grep log for the warning; confirm no regressions in the loading screens and DMA-heavy scenes.
2. Serdes hardening check (low risk): in common/serdes.h Reader::Read(auto&) / Read(std::string&) confirm element count and string length are rejected when > container size (their lines) and `v.reserve` is guarded; otherwise a corrupt blob can request a multi-GB allocation (std::bad_alloc, not CorruptData). Test: truncate/flip bytes in a pipeline blob in the shader cache dir, start the game, expect "Clearing cache" and a clean boot.
3. Optional: honour BbToggle::TextureCollector in GarbageCollectImages (texture_cache.cpp ~1207 after the stats stores) as an A/B kill switch. No behaviour change by default.
Nothing else in 196ba93 is missing from ours; do not port their PipelineCompiler (no exception safety, unbounded queue, pointer lifetimes, leaking target_streaks).

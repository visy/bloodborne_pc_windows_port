Offensive-name filter data (read by scripts/namefilter.py and gpu/shim/party/name_filter.cpp; both implement the same
spec, documented at the top of scripts/namefilter.py, and are tested against the same vectors, tests/name_filter_vectors.txt).

  charmap.tsv    GENERATED by tools/name_filter/gen_charmap.py from Unicode data and TR39 confusables.txt
                 (UNICODE_LICENSE.txt). Case, accents, look-alike letters, invisible characters, separators.
  strict.txt     TERM FLAG  - tier A: unambiguous slurs and hate terms. FLAG s = also inside longer words and across
                 separators, t = whole word only (plus its plural), x added (sx, tx) = the doubled letters belong to the
                 word. Letter runs are folded, so one spelling covers repeats.
  identity.txt   tier B: protected-group words. S = strong, W = weak (needs a plural or a people word).
  people.txt     tier B: words that make a weak identity word a group (ppl, people, folks ...).
  violence.txt   tier B: hostile words. A = ambiguous (hunter, killer ...), H = hate word (hater, genocide ...).
  link.txt       tier B: filler words allowed inside a compound.
  codes.txt      tier C: numeric codes, slogans, symbols (format at the top of the file).
  allow.txt      ordinary words and places that contain a strict term (w = whole word, c = fragment).

After editing any file here, run:   python tools/name_filter/gen_embed.py   (rebuilds the embedded copies the lobby service,
the launcher and the game use when no data folder is found), then   python -m pytest tests/test_name_filter.py
Add a positive or negative example to tests/name_filter_vectors.txt (tools/name_filter/gen_vectors.py makes it).
The game also reads a folder named name_filter next to it, or BB_NAME_FILTER_DIR, in place of the embedded copy.

### Changed
- **The loading screen stays up until the world runs smoothly in a solo game too** (hitch082b) the first frames after a load are heavy (the world's first draw: 80-190 ms, then about half a second of uneven frames) and a solo game showed them as a stutter right at the lamp; a party game already kept the loading screen up over them (*Hold the screen until smooth*). The same setting now acts outside a party: the screen stays 1.0-1.9 s longer (until frames have run under 50 ms for 1 s, at most 3 s) and the world appears running smoothly. Turn *Hold the screen until smooth* off for the old behaviour everywhere, or set `BB_SETTLED_DROP_SOLO=0` for solo games only.

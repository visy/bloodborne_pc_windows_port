### Changed
- **The seamless loading switches are on by default**: *Hold the screen until smooth* joins *Load with the host*, *Arrive beside the host* and *Rejoin in place*, which were already on. A new install, or a bbport.ini without the key, gets all four; each stays a System > My party: Loading row, a launcher checkbox and an ini key (`party_settled_drop`, `party_parallel_follow`, `party_load_beside`, `party_quick_rejoin`), and a saved 0 stays 0.

### Changed
- **The in-game System menu is grouped into Game Settings and Party Settings** (from Nightwatch, by zarok-lazarus). System now has *Game Settings*, *Party Settings* and *Exit Game*. *Game Settings* holds Controls, Environment, Brightness and the port's other pages (Display, Sound, Effects, Game HUD, Game patches ...); *Party Settings* holds every page with "party" in its name (Party, Party mode, Party rules ..., My party ...). The game's dead *Network* entry is gone. The settings paths in the docs and the launcher now read *System > Party Settings > ...* and *System > Game Settings > ...*. If the game's menu code is not as expected, the old flat list is used.

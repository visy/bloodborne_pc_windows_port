### Fixed
- **Map pieces loaded without their model or collision** (Jgamrot 1e6fb99) the game reads its archives with a seek plus read on one thread and with a positional read on another; on Windows the positional read moved the file position and put it back, so a read in between could land in the wrong place. Reads, writes and seeks on one file now take turns. `BB_FILE_OFFSET_LOCK=0` restores the old behaviour.
- **GPU command stream: constant-engine wait compared the wrong way round** (Jgamrot 682e7f1, shadPS4 e6c79a5fe) the wait for the draw engine used an unsigned difference that wrapped around when the constant engine was ahead. `BB_CE_DE_COUNTER_FIX=0` restores the old compare.
- **Engine stop on a layout change past an image's mips or layers** (Nightwatch 76545f3, Lantern Engine by Awaken) a view of more than the cached image has no longer stops the game; the missing part is left out and a line is logged. `BB_IMAGE_BARRIER_SKIP=0` restores the old stop.
- **Earlier game stuck in the graphics driver is now reported at start** (bbhost 9df4166, by intent) a bbport.exe that cannot end and still holds its memory is named in the log and in a box nothing waits on; the game starts as before. `BB_STUCK_WARNING=0` turns it off.

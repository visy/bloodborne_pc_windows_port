### Fixed
- The Hunter's Dream (and other scenes) no longer render tinted red with a cyan sky when the texture cache collector is under memory pressure: the collector wrote GPU-rendered tiled textures (such as the 3D color-grading texture) back to game memory as linear rows and then freed them, so they were rebuilt from scrambled data. Such textures now stay until they can be written back faithfully. This lets the texture cache budget cap of 1536 MiB (leak081c) stay on, which keeps memory flat over a long session (private memory +46 MB and GPU memory +120 MB over 25 minutes in the perf route, against about +590 and +470 MB without the cap). `BB_GC_BUDGET_CAP=0` turns the cap off, `BB_GC_BUDGET_CAP_MB=N` changes it.

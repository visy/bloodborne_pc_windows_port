### Fixed

- **Wedges of light in the shadows of lamps and other point lights** (deadinside28 0fc2921c) the point light's shadow cube is cleared by a compute shader one face at a time; only whole-image clears were recognised, so the other faces kept older shadows. A clear of exactly one face of an array or cube image now clears that face. `BB_CLEAR_LAYER=0` restores the old behaviour.
- **Stretched vertices where a buffer crossed a boundary between two pieces of a grown heap** (deadinside28 0fc2921c) a read that lay across two guest memory pieces was served from a VRAM copy that could be stale where the GPU had written in place. It is now copied piece by piece, in command order. `BB_LAYER_STITCH=0` restores the old behaviour.
- **Frame rate drop after quitting to the title and loading another save** (deadinside28 0fc2921c) marks the previous save's loading left on memory made the next area's GPU data be written in place over the bus. The marks now expire after `BB_LAYER_CPU_MARK_SECONDS` (default 5, 0 keeps them as before) when a whole GPU write meets them, unless the CPU still uses the block.
- **Occlusion queries count samples only inside the game's open queries** (deadinside28 0fc2921c, for `BB_OCCLUSION_QUERIES=1`) the segments of real occlusion queries now run only between a query's begin and end events, saving the result copies for samples nobody reads. `BB_OCCLUSION_INTERVALS=0` counts all the time.
